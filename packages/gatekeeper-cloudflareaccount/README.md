# Cloudflare Account

Uses a deployment Cloudflare API token. Native GET/HEAD operations are observations; other methods enter the approval queue. The account is revocable, and writes carry a credential-generation fence. The uploaded implementation is preserved verbatim.

The package includes the restored session types, text declarations, Worker exports, and
Durable Object migrations. It is built and wired through the Starter; see
[the startup guide](../../docs/startup.md). No custom tests were added.
